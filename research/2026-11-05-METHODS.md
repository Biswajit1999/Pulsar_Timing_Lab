# Independent pulsar phase and chromatic sensitivity (5 November 2026)

Two controlled numerical analyses, not fits to NANOGrav data:

1. Fixed-period weighted least squares for an offset, linear trend and sine/cosine timing perturbation. Reports the *conditional* covariance (known, independent Gaussian per-epoch standard deviations). A scan across trial periods would require a look-elsewhere correction; the returned chi-square is not evidence of a planet or gravitational wave.
2. Cold-plasma frequency-dependent differential dispersion delay with the reference frequency explicit. Input DM is pc cm^-3, frequencies MHz, output seconds. This is not a timing-model refit.

Run from the research directory: `python -m unittest -v test_phase_robustness.py` (requires numpy). Four deterministic tests check coefficient recovery, uncertainty scaling, dispersion law and rank rejection.

Synthetic test inputs only. No telescope data were newly retrieved. Scientific code prepared with AI assistance; Git commit attribution follows the configured repository identity.
