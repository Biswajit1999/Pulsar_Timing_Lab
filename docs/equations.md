# Numerical Kernel: Data Products, Equations And Units

## Observation Layer

The primary products loaded by `assets/js/physicsWorker.js` are not generated by the
simulation:

- `res_ave/<pulsar>.ares` values from the NANOGrav 11-year release provide residual values and
  reported uncertainty in microseconds at decimal-year epochs.
- `dmx_vals/<pulsar>.dmx` values provide relative dispersion-measure contributions, uncertainty
  and MJD epochs.

Residual decimal years are converted for the graphical MJD axis by interpolating between the
UTC start of the stated calendar year and the UTC start of the next year:

```text
MJD_display = MJD(UTC year start) + fraction_of_calendar_year * days_in_year
```

The original decimal-year values remain part of the exported observation table. No refit,
whitening or subtraction is applied to the released values.

## Optional Overlay Independent Variable

When the overlay is enabled, its elapsed time is sampled at each displayed residual epoch:

```text
tau = (MJD_display - MJD_display,0) * 86400 s
```

## Rotational Phase Ephemeris

```text
N_model(tau) = N0 + nu tau + 0.5 nudot tau^2
nu = 1 / (period_ms * 1e-3)
```

`N_model` is pulse phase in cycles, `nu` is in `Hz`, and `nudot` is in `Hz s^-1`.

## Instantaneous Glitch Injection

For a glitch epoch `tau_g` and fractional frequency step `g = Delta nu / nu`:

```text
Delta nu = nu g
Delta N(tau) = 0                                  tau < tau_g
Delta N(tau) = Delta nu (tau - tau_g)            tau >= tau_g
nu_model(tau) = nu + nudot tau
R_glitch(tau) = -Delta N(tau) / nu_model(tau)
```

The worker evaluates the residual in seconds internally and sends microseconds to the
renderer. This amber injection is separate from the cyan released residual product.

## Cold-Plasma Dispersion Calculator

For band-edge frequencies expressed in MHz:

```text
Delta t_seconds = D DM (nu_low^-2 - nu_high^-2)
D = 4.148808e3 s MHz^2 pc^-1 cm^3
```

The value is positive for `nu_low < nu_high`. It is a model telemetry calculation and does
not fabricate a dynamic spectrum for a release that contains residual and DMX tables.

## Stochastic Timing-Noise Injection

The optional red-noise sequence is constructed as:

```text
r(i) = sum_k [a_k cos(2 pi k i / (n - 1)) + b_k sin(2 pi k i / (n - 1))]
std(a_k), std(b_k) proportional to k^(-gamma / 2)
```

After its finite-sample mean is removed, the series is rescaled to the requested RMS in
seconds. Independent Gaussian white noise is added separately.
