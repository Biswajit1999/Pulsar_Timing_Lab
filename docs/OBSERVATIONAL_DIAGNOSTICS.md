# NANOGrav 11-year descriptive diagnostics

Run `python tools/validate_observations.py`, `python -m unittest discover -s tools -p 'test_observational_diagnostics.py'`, then `python tools/observational_diagnostics.py` from the repository root. The last command reads the *bundled, released* residual and DMX JSON and writes `data/observations/nanograv_11yr_diagnostics.json`. The source is NANOGrav's 11-year release (Arzoumanian et al. 2018, ApJS 235, 37); the provenance field is copied from the bundled product.

The new diagnostics are: (1) uncertainty-weighted residual mean, RMS, and chi-square about a constant, (2) binned pairwise residual structure function, with an explicitly approximate measurement-noise subtraction, and (3) an uncertainty-weighted linear *descriptive* trend in released DMX values. Decimal-year bins are in years; DMX slope is in pc cm^-3 day^-1. An empty lag bin has `null` statistics.

**Interpretation boundary.** Published residuals depend on the NANOGrav timing-model fit. Samples are heteroscedastic, irregularly spaced, and may be correlated; pairs in the structure function reuse samples and are not independent. Formal chi-square and slope uncertainties assume independent Gaussian errors and should **not** be used as significance claims. Negative noise-subtracted structure-function values are retained rather than clipped. This is not a PTA gravitational-wave-background analysis, an independent timing solution, a red-noise power-spectrum fit, or a detection of interstellar dispersion evolution. A scientifically defensible astrophysical inference requires a joint timing/noise model, selection-effect treatment, and suitable covariance.
