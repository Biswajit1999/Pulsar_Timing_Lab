# NANOGrav DMX covariance and chromatic sensitivity

This module complements (rather than duplicates) the earlier `research/2026-10-15-nanograv-diagnostics` branch, which already implemented independent-error DMX trends and residual structure functions. New analyses are: (1) generalised least-squares DMX slopes under an explicitly **hypothetical** exponential covariance kernel, (2) leave-one-time-block-out slope sensitivity, and (3) propagation of released DMX and formal uncertainty into differential cold-plasma receiver-band delays. The kernel is `C_ij = sigma_i² delta_ij + a² exp(-|t_i-t_j|/tau)`; `a` and `tau` are not inferred from observations.

Run `python -m pip install numpy`, `python -m unittest discover -s tests -v`, and `python tools/run_timing_robustness.py --output outputs/timing_robustness.json` from the repository root. The runner reads the unchanged retained NANOGrav 11-year JSON asset and compares zero covariance amplitude with an assumed amplitude equal to the median formal DMX uncertainty and a 0.5-year correlation time. It also tests annual-block deletion and summarizes frequency-band delays in microseconds.

**Limitations:** released DMX values are timing-model-dependent and may be correlated by fitting; an exponential covariance is a sensitivity assumption, not a validated physical noise process. Formal GLS slope errors condition on those hyperparameters, block deletion is not a confidence interval, and DMX-derived band delays are relative offsets, not absolute arrival-time predictions. This does not establish a new ISM trend, a pulsar timing solution, or PTA gravitational-wave significance.
